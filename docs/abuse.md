# 滥用举报与处置

VidRoom 是装在用户自己电脑上的本地应用:视频在用户的显卡上生成,成片只存在用户自己的硬盘里,**不经过、也不上传到 VidRoom 维护者的任何服务器**。这决定了维护者能做什么、不能做什么,下面如实写明。

## 怎么举报

- 应用内:菜单「举报滥用」,会打开下面这个 issue 模板。
- 直接开 issue:<https://github.com/Davids-G1t/VidRoom/issues/new?template=abuse-report.yml>(自动打 `abuse` 标签)。
- 举报违反 MiniMax H3 许可或使用政策(见 [`USE-POLICY.md`](USE-POLICY.md))的使用或内容,也可以同时向模型权利人 MiniMax 反映。

**不要把违规视频、截图原件贴进公开 issue。** 用文字描述,给出公开可访问的链接(如果有),维护者需要证据时会另外私下联系。

## 维护者收到举报后做什么

1. **7 天内回复**:确认收到,判断是否属于 VidRoom 能处置的范围。
2. **核实**:对照 [`USE-POLICY.md`](USE-POLICY.md)(MiniMax H3 许可第 V 节与附件 A)判断是否违规。证据只在私下留存,不放进公开仓库。
3. **能做的处置**(都在维护者控制范围内):
   - 修改应用内聊天助手的系统提示词,让它拒绝同类请求;
   - 在后续版本里加强防护,发布更新;
   - 对 GitHub 仓库里的违规内容(issue、评论、PR 等)删除或隐藏,对反复违规的账号在仓库内封禁;
   - 如果举报涉及的是基于 VidRoom 分发的改版或托管服务,联系其发布者要求停止。
4. **结案**:在 issue 里写明处置结果并关闭(不公开举报人身份与证据细节)。

## 做不到的事(如实说明)

- **删不了用户电脑上已经生成的文件。** 成片保存在用户本机,维护者没有任何远程访问或远程删除能力,应用也不会回传数据。
- **看不到谁在用、生成了什么。** 应用不带遥测,维护者无从知道某个视频是谁生成的。
- **不能阻止已下载的旧版本继续运行。** 更新只对安装新版本的用户生效。
- 已经被传到第三方平台的内容,请向该平台举报;VidRoom 维护者无权删除。

如涉及违法内容(尤其是涉及未成年人的内容),请直接向当地执法机关报告。
